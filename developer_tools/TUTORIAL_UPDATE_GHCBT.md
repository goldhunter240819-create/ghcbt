# 🚀 Tutorial Operasional Smart Update GHCBT (Edisi Klik-Klik)

Panduan ini menjelaskan cara baru yang lebih gampang untuk melakukan pembaruan sistem.

---

## 🛠️ BAGIAN 1: Untuk Anda (Cara Bungkus Update - Sekali Klik)
Lakukan ini di komputer localhost Anda saat ingin merilis fitur baru ke client.

### Langkah-langkah:
1.  Buka folder project GHCBT Anda di File Explorer.
2.  Cari file bernama **`GAS_UPDATE.bat`** (Ikonnya gambar roda gigi).
3.  **Klik Dua Kali** pada file tersebut.
4.  Jendela Hitam akan muncul. Masukkan nama versinya:
    *   Contoh: `v1.2 - Paket Anti Lemot`
    *   Lalu tekan **Enter**.
5.  Tunggu sampai ada tulisan **"BERHASIL!"**.
6.  Selesai! File ZIP update sudah tercipta di folder Anda.

---

## 📥 BAGIAN 2: Untuk Client (Cara Pasang Update)
Kirim file ZIP tadi ke client, lalu minta mereka melakukan ini:

### Langkah-langkah:
1.  Login ke Dashboard Admin GHCBT.
2.  Masuk ke menu **"Update System"** di paling bawah sidebar.
3.  Tarik (Drag) file ZIP tadi ke kotak upload.
4.  Klik tombol biru: **"JALANKAN UPDATE"**.
5.  Klik **"Ya, Jalankan"**.
6.  Sistem otomatis membackup data lama dan memasang update. Selesai!

---

## 🛡️ Kenapa Sistem Ini "Kelas Dewa"?
1.  **Anti Ribet**: Anda tinggal klik dua kali, client tinggal upload.
2.  **Anti Panik**: Foto siswa & logo sekolah aman, tidak akan hilang tertimpa.
3.  **Anti Error**: Sistem otomatis membackup database sebelum mulai.
